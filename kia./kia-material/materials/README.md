# استودیوی متریال

**کیا — Kia Material › `materials`**

این پوشه بخشی از چیدمان رسمی پروژه است و فعلاً کدی در آن نیست.
برنامه‌ریزی شده برای این حوزه: متریال‌های نهایی‌شده و انتشار‌یافته

> این دپارتمان به‌صورت مستقل (مثل یک پروژه جدا) توسعه می‌یابد؛
> نقطه اتصال آن `apps/api` + `apps/group` و هستهٔ مشترک `packages/platform` است.
