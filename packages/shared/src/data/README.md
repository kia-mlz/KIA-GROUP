# Iran provinces and cities

Vendored local dataset for signup / profile location fields.

- File: `iran-provinces-cities.json`
- Source: [iran-cities-json@2.0.0](https://www.npmjs.com/package/iran-cities-json) (based on [ahmadazizi/iran-cities](https://github.com/ahmadazizi/iran-cities) via [jd1378/iran-cities-json](https://github.com/jd1378/iran-cities-json))
- Coverage: 31 provinces and ~1,300 cities (Persian names)
- Used through `@kia./shared` helpers in `utils/iran-geo.ts` — no runtime third-party API
